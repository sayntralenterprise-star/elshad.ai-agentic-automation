# Slice S1.4 Demo Script — Multi-agent v1: Supervisor + Specialists, Typed Handoffs, Shared Blackboard & Team Canvas

## 1. Overview & Business Value
Slice S1.4 delivers collaborative multi-agent execution for Elshad. Rather than relying on a single monolithic prompt, complex tasks are decomposed across a **Supervisor Agent** and dedicated **Specialist Agents** (e.g. Incident Triage Supervisor delegating to Auth Specialist, Billing Specialist, and Network Infrastructure Specialist).

Key capabilities demonstrated:
1. **Supervisor + Specialists Team Architecture:** Visual team topology configured via Studio Team Canvas.
2. **Typed Handoffs (FR-RT-21):** Rigidly typed handoff contracts containing `{ goal, context_summary, artifacts[], constraints, return_schema }`.
3. **Run-Scoped Shared Blackboard (FR-RT-22):** State board with per-agent `read_keys` and `write_keys` isolation and optimistic version concurrency (`CAS`).
4. **Child Runs & Cost Roll-Up (FR-RT-20):** Child runs inherit parent identity, tenancy, and policies; all micro-USD spend and tokens roll up to root run ledger.
5. **Delegation Guardrails (FR-RT-23, FR-RT-24):** Max delegation depth (3) and fan-out (8) prevent runaway loops; all inter-agent messages are captured in trace logs.
6. **Console Team Canvas (§7.3.3):** Interactive graph with supervisor/specialists, edge schema inspection, per-agent limit badges, and simulation animation.

## 2. Step-by-Step Demo Flow

### Step 1: Create Multi-Agent Team with Supervisor & Specialists
- Navigate to Agent Studio -> **Teams**.
- Create team: "Incident Triage & Remediation Team" (`supervisor_specialists` pattern).
- Assign Supervisor: `incident-triage-supervisor`.
- Add Specialists:
  - `auth-specialist` (read: `[auth_token, user_profile]`, write: `[session_state]`)
  - `billing-specialist` (read: `[user_profile, order_id]`, write: `[refund_status]`)
  - `network-specialist` (read: `[endpoint, error_code]`, write: `[infra_diagnosis]`)

### Step 2: Define Typed Handoff Contracts
- On the Team Canvas, click the edge between `incident-triage-supervisor` and `billing-specialist`.
- Inspect typed handoff schema requiring:
  - `goal`: "Verify refund eligibility and process refund"
  - `artifacts`: order invoice receipt and user claim
  - `constraints`: max refund limit $500
  - `return_schema`: `{ refund_status: string, transaction_id: string }`

### Step 3: Run Multi-Agent Benchmark Task
- Launch run: "Customer #4829 reports unauthorized $240 charge and locked session".
- Observe trace:
  1. Supervisor parses input and writes `user_id` and `charge_amount` to blackboard.
  2. Supervisor hands off to `auth-specialist` to verify session legitimacy.
  3. Supervisor hands off to `billing-specialist` with typed handoff payload.
  4. Both specialists update their scoped blackboard keys.
  5. Child runs complete; spend rolls up into root run ledger.

### Step 4: Verify Delegation Guardrails
- Trigger test with simulated depth = 4.
- Delegation Engine cleanly rejects with `ERR_DELEGATION_DEPTH_EXCEEDED`.
- Trace logs inter-agent rejection message with full audit trail.

### Step 5: Accessibility & UX
- Team Canvas passes axe-core accessibility checks.
- Keyboard navigation between nodes and inspectors operates smoothly.
