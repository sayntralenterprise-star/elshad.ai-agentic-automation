# Slice S0.1 — 3-Minute Demo Script & DoD Checklist

## 3-Minute Walkthrough

1. **Start & Health Check (0:00 – 0:45)**
   - Run `docker compose -f deploy/docker-compose/compose.yaml up --build` (or run API + Console in dev).
   - Verify `GET http://localhost:8080/health`, `GET http://localhost:8080/ready`, `GET http://localhost:8080/openapi.json`, and `GET http://localhost:8081/health`.
2. **Sign In & Tenancy Shell (0:45 – 1:30)**
   - Open `http://localhost:3000`, sign in with `admin@elshad.local` / `ChangeMe123!`.
   - Confirm `Default Organization`, `Default Workspace`, and `DEV` environment badge in TopBar.
   - Switch environment from `DEV` → `PROD`: verify URL updates to `/w/default/e/prod/home` and the red production border + safety banner appear.
   - Switch theme (`Light` → `Dark` → `High-Contrast`) and open the Command Palette with `Ctrl/Cmd + K`.
3. **Create & Use API Key (1:30 – 2:20)**
   - Navigate to `Settings` → enter `"Demo CLI Key"` → click **Create API Key**.
   - Copy the one-time secret (`key_...`) displayed in the confirmation banner.
   - Call `GET http://localhost:8080/api/v1/workspaces` with `Authorization: Bearer <secret>` and inspect `X-RateLimit-*`, `X-Request-Id`, and `X-Trace-Id` response headers.
   - Revoke the key in Console and confirm subsequent calls with that key return `401 AUTH_UNAUTHENTICATED`.
4. **Inspect Immutable Hash-Chained Audit Log (2:20 – 3:00)**
   - Navigate to `Governance` to view `auth.login`, `api_key.create`, and `api_key.revoke` events with sequential `seq` and SHA-256 `hash` values.
