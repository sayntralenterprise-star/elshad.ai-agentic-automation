# Slice S1.7 Demo Script — Environments + CLI: Promotions, Unmapped Credential Gate, Rollback & `agentctl`

## 1. Overview & Business Value
Slice S1.7 delivers safe, auditable environment promotions (`dev` -> `staging` -> `prod`), 1-click rollback, and the `agentctl` developer CLI for CI/CD and Git-ops workflows.

Key capabilities demonstrated:
1. **Promotion Pipeline (N.2.13):** Verifies published version, checks eval gate scores, computes diff vs live version, and validates credential mappings.
2. **Unmapped Credential Guard:** Attempting to promote an agent/workflow whose required connections are not mapped in `prod` is immediately blocked with a clear, actionable error.
3. **Separation-of-Duties Approvals & Canary Traffic:** Production promotions require approval from a distinct principal and support canary traffic splits (e.g. 10%).
4. **1-Click Rollback:** Restores the previous live version in target environment immediately.
5. **`agentctl` CLI (B.7):** Supports `login`, `init`, `run`, `trace`, `eval run`, `deploy`, `rollback`, `diff`, and `tool test`.
