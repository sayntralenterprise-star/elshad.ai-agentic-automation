# Slice S1.6 Demo Script — Connectors Wave 1: Connector SDK, D17 Catalog & Write-Only Connections

## 1. Overview & Business Value
Slice S1.6 delivers the declarative Connector SDK and all 16 **Wave 1 (D17)** first-party connectors (`http_rest`, `postgres`, `slack`, `gmail`, `outlook`, `google_workspace`, `jira`, `github`, `zendesk`, `salesforce`, `hubspot`, `notion`, `stripe`, `s3`, `teams`, `twilio`), backed by write-only credential vaulting, per-environment mapping, and strict outbound egress allowlists.

Key capabilities demonstrated:
1. **Connector SDK & D17 Wave 1 Catalog (FR-INT-1, FR-INT-6, D17):** Declarative manifests with auth types, triggers, actions, pagination, rate limits, and recorded test fixtures.
2. **Contract Verification Against Recorded Fixtures (D.2):** Every Wave 1 connector runs deterministic contract tests against recorded fixtures.
3. **Write-Only Credential Vault & Environment Mapping (FR-INT-2, FR-INT-3, P.4):** Secrets are encrypted on write, masked in all responses (`"Stored — never revealed"`), and injected only at call time.
4. **Outbound Egress Domain Controls (FR-INT-5):** Connectors declare required domains; unauthorized outbound calls are blocked and audited.
5. **Console Connectors Gallery & Connections UI (§7.3.7, P.4):** Browse connectors by category, run contract tests, configure connections, test health, and rotate secrets.
