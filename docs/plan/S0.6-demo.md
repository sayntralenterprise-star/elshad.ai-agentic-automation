# Slice S0.6 — 3-Minute Demo Script, DoD Checklist & Phase 0 Exit Gate

## 3-Minute Walkthrough

1. **Write-Only Envelope Secrets Vault & Rotation (`E0.6-1`, `F.3`) (0:00 – 0:45)**
   - Navigate to `Governance` in the Web Console (`/w/default/e/dev/governance`).
   - Under **Secrets Vault (AES-256-GCM Envelope)**, store a new credential `stripe_api_key` (`POST /api/v1/secrets`). Observe the UI displays only the metadata (`ref: secret://db/...`, `key_version: 1`) — never returning plaintext.
   - Click **Rotate Secret** (`POST /api/v1/secrets/{id}/rotate`) and observe `key_version` increments to `2`. Verify `scanForSecretLeaks` finds zero plaintext secrets across API responses, run steps, and audit logs.

2. **Budgets & 1-Step Hard Stop Enforcement (`E0.6-2`, `N.2.6`) (0:45 – 1:35)**
   - Under **Budgets & Hard Stops**, configure an `agent` budget with a tight `hard_limit_micro_usd` (`100`) and breach policy `stop` (`POST /api/v1/budgets`).
   - Execute an agent run (`POST /api/v1/agents/{id}/runs`) whose first LLM step exceeds `100` micro-USD. Verify `executeReActAgentRun` emits soft-limit alert and halts the runaway agent within **1 step** (`status: "budget_exceeded"`, `error.code: "BUD_HARD_LIMIT"`, `0` tool calls executed).

3. **Emergency Kill Switch (`<= 5 s`) & Banner (`E0.6-3`, `C.8`) (1:35 – 2:20)**
   - Click **Activate Kill Switch** (`POST /api/v1/killswitches`) for scope `global`.
   - Observe the **Emergency Kill Switch Active** alert banner and attempt to launch a run — it is blocked immediately (`403 POL_DENIED`) within milliseconds (`<= 5 s` SLA) and audited (`killswitch.activate`). Click **Deactivate** to restore normal operations.

4. **Audit Chain Verify & Backup/Restore DR Drill (`E0.6-4..6`) (2:20 – 3:00)**
   - Click **Verify Audit Chain** (`GET /api/v1/audit/verify`) to confirm `valid: true` across the SHA-256 hash chain.
   - Run `node deploy/scripts/backup-restore.mjs --drill` and review [S0.6-performance-baseline.md](S0.6-performance-baseline.md) + [quickstart-and-concepts.md](../guides/quickstart-and-concepts.md).
