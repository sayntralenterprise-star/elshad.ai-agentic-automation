# Slice S0.3 — 3-Minute Demo Script & DoD Checklist

## 3-Minute Walkthrough

1. **Create & Inspect a Versioned Agent (0:00 – 0:45)**
   - Navigate to `Agents` in the Web Console (`/w/default/e/dev/agents`) and click **+ Create Agent**.
   - Fill kebab-case name `ops-triage-agent`, model tier `standard`, autonomy `L2`, system prompt, and starter tool `current_time`, then submit **Create Agent Draft** (`POST /api/v1/agents`).
2. **Tools, Lethal-Trifecta Detection & Versioning (0:45 – 1:40)**
   - Switch to the **Tools** tab and enable a confidential read tool alongside `web_fetch` (`untrusted_source`) and `http_request` (`external_comms`). Observe the live **Lethal Trifecta Warning** alert (`FR-TL-5`).
   - Narrow external tool domains (`allowed_domains`) or adjust approval modes (`auto` / `always`), save a new draft `1.1.0` (`PATCH /api/v1/agents/{id}`), click **Diff Versions** (`GET /api/v1/agents/{id}/diff`), and click **Publish Version** (`POST /api/v1/agents/{id}/versions/{vid}/publish`).
3. **Playground Run, ReAct Trace & Usage Ledger Reconciliation (1:40 – 2:30)**
   - Switch to **Test Playground**, test safely with the **Dry-run** toggle (`FR-TL-9`), or execute a live ReAct run (`POST /api/v1/agents/{id}/runs`).
   - Observe the step-by-step ReAct trace (`llm_call` + `tool_call`), integer micro-USD cost ticker, and itemized `GET /api/v1/runs/{id}/usage-ledger` reconciliation where `SUM(usage_ledger.cost_micro_usd) === run.cost_micro_usd`.
4. **Security & Runtime Verification Guards (2:30 – 3:00)**
   - SSRF guard (`assertSafeOutboundUrl`) blocks loopback, RFC1918, cloud metadata (`169.254.169.254`), and IPv4-mapped IPv6 (`[::ffff:7f00:1]`) targets.
   - `ToolGateway` + `DefaultV1PolicyEvaluator` enforce `POL_UNTRUSTED_CONTEXT`, scrub leaked tokens (`[REDACTED:api_key]`), wrap tool outputs in `<tool_result>` tags, and enforce isolated JS VM / Python sandbox resource bounds.
   - Loop detector halts runaway agents cleanly (`RUN_LOOP_DETECTED`), and structured-output agents perform 1 automatic JSON repair pass (`FR-RT-9`).
