## 2. Walkthrough Highlights

1. **Durable Pause on `POL_APPROVAL_REQUIRED` (`FR-ORC-4`, `N.1`):**
   - When an agent invokes a tool marked `approval: 'always'` (or gated by an enforced `require_approval` policy), `POST /api/v1/agents/{id}/runs` transitions the run to `waiting_approval`, persists an M.4 `ApprovalRecord`, and dispatches Slack & email notifications with single-use HMAC-SHA256 signed action links.
2. **7-Day Survival & Upgrade Durability (`E1.1`):**
   - `ApprovalService.exportState()` / `importState()` preserves pending approvals, escalation rules, and consumed single-use token JTIs across restarts (`7`-day default SLA).
3. **Slack / Email Signed Callback & `< 5s` Resume (`E1.1`, `D.4`):**
   - `POST /api/v1/approvals/slack/action` verifies `x-slack-signature` + single-use action token, enforces Separation of Duties (`FR-GOV-12`), marks the token consumed (preventing replay), and signals `ExecutionEngine` so the paused run resumes to `queued` in under `5s`.
4. **Split Approvals Inbox UI (`§7.3.6`, `P.3`):**
   - Navigate to `/w/default/e/dev/approvals` to inspect AI summaries, before/after diffs, evidence, policy reasons, edit-and-approve payloads, high-risk `APPROVE` keyword confirmation, request info, delegation, snooze, and dispatched Slack/email notifications.
