# Slice S0.4 — 3-Minute Demo Script & DoD Checklist

## 3-Minute Walkthrough

1. **Create & Publish a Starter Workflow (`Webhook -> Agent -> Switch -> Slack`) (0:00 – 0:45)**
   - Navigate to `Workflows` in the Web Console (`/w/default/e/dev/workflows`) and click **+ New Workflow**.
   - Keep the prefilled starter workflow (`Inbound Webhook -> Agent Triage -> Priority Switch -> Slack Notify`) and click **Create Workflow** (`POST /api/v1/workflows`).
   - Click **Validate** (`POST /api/v1/workflows:validate`) to run static DAG, cycle, JSONata, and trigger checks, then click **Publish & Activate** (`POST /api/v1/workflows/{id}/versions/{vid}/publish`) to register the active inbound webhook trigger (`GET /api/v1/triggers`).

2. **HMAC/Token/JWT Webhook Auth & Replay Protection (0:45 – 1:25)**
   - Send a signed webhook request to `POST /api/v1/hooks/{externalId}` (captured with raw request body verification and 5-minute timestamp skew enforcement).
   - Re-send the exact signed event / timestamp within the replay window and verify duplicate delivery is rejected with `409 RES_CONFLICT` (`TriggerService` + `trigger_events`).

3. **Lossless YAML Round-Trip, Pinning & Test-from-Here (1:25 – 2:10)**
   - Click **View as YAML** to inspect `yaml_source` and edit/re-apply cleanly via `PATCH /api/v1/workflows/{id}` (`serializeWorkflowToYaml` / `parseWorkflowFromYaml`).
   - Select **Agent Triage** on the Canvas, enable **Pin Output Data (Test-from-Here)** (`pinned_data`), and click **Test from Selected Node** (`POST /api/v1/workflows/{id}/runs` with `pinned_data` + `start_from_node_id`).

4. **Checkpointed Crash Recovery & 300-Node Canvas Scale (2:10 – 3:00)**
   - In `@elshad/workflow-core` tests, a 50-node graph with 3 parallel fan-out branches and a 1,000-item `logic.loop` checkpoints per iteration and resumes cleanly across worker restart (`InMemoryExecutionEngine` + `InMemoryEffectLedger`).
   - Click **Load 300-Node Benchmark** in the Workflow Canvas and verify viewport culling keeps rendered DOM node cards below 50 while rendering in under 1 second.
