# Slice S0.2 — 3-Minute Demo Script & DoD Checklist

## 3-Minute Walkthrough

1. **Enqueue & Execute a Durable Run (0:00 – 0:50)**
   - Navigate to `Runs` in the Web Console (`/w/default/e/dev/runs`) and click **Start Durable Run** (or `POST /api/v1/runs` with `Idempotency-Key` and `simulated_steps`).
   - Observe the run execute steps, record usage (`steps`, `cost_micro_usd`), commit checkpoints, and transition `queued → running → succeeded`.
2. **Inspect Trace Spans & SSE Stream Resume (0:50 – 1:40)**
   - Click **Inspect Trace** to view the virtualized span tree (`role="tree"`), and click a step row to inspect its `idempotency_key`, latency, and token metrics in the Right Inspector Drawer.
   - Stream live run events via `GET /api/v1/runs/{id}/events?stream=true` and reconnect with `Last-Event-ID: 2` to verify zero duplicated or skipped events.
3. **Crash Resilience, Timers & Cancel Propagation (1:40 – 2:20)**
   - Demonstrate worker lease expiry & automatic re-claim from the last checkpoint (`requeueExpiredLeases`) with `InMemoryEffectLedger` deduplicating side effects via `sha256(run_id:step_seq:attempt_group)`.
   - Verify illegal transitions (e.g., cancelling a terminal `succeeded` run) return `409 RES_CONFLICT`.
4. **DLQ & Bulk Re-drive (2:20 – 3:00)**
   - Switch to the **DLQ** tab in the Runs page (or call `GET /api/v1/dlq`), view exhausted failed runs, and click **Re-drive** (`POST /api/v1/runs:bulk-redrive`) to transition them back to `queued`.
