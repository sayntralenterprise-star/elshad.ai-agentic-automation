## 2. Walkthrough Highlights

1. **Exhaustive O.1 RBAC Matrix & Custom Roles (`FR-GOV-2`, `O.1`):**
   - `verifyO1RolePermissionMatrix()` in `packages/authz` validates every built-in role (`org_owner`, `workspace_admin`, `builder`, `operator`, `reviewer`, `auditor`, `viewer`) across all 60 permissions and 4 scope/ownership contexts (`own`, `other`, `cross-workspace`, `cross-org`).
   - `POST /api/v1/roles` creates org-scoped custom roles evaluated dynamically during API authorization.
2. **Scoped Agent Identities & `on_behalf_of` Attribution (`FR-GOV-1`, `F.1`):**
   - `POST /api/v1/agent-identities` provisions non-human `principal` identities scoped to an `(agent_id, environment_id)` pair and explicit `allowed_tool_ids`.
   - `POST /api/v1/agent-identities/{id}/token` issues short-lived `AgentIdentityRuntimeToken` payloads and logs `agent_identity.token_issue` to `audit_events` with `on_behalf_of`.
3. **Scoped Tool Grants & Separation of Duties (`FR-TL-3`, `O.1`):**
   - `POST /api/v1/tool-grants` binds narrowed `allowed_domains`, `allowed_methods`, and `max_calls_per_run` to an agent.
   - Write, destructive, and external-comms tool grants enforce `assertSeparationOfDuties` (`POL_DENIED` on single-user self-approval) and require a distinct `tool:grant_write` approver.
4. **Declarative Policies, Rego Compilation & 10,000-Run Simulation (`FR-GOV-4..11`, `D7`):**
   - `POST /api/v1/policies` compiles structured rules to OPA/Rego (`package elshad.governance.<slug>`, `import rego.v1`) in `audit_only` mode by default.
   - `POST /api/v1/policies/simulate` evaluates historical runs (verified up to 10,000 runs in well under 5s, meeting the `< 60s` target).
   - `POST /api/v1/policies/{id}/enforce` enforces 2-person SoD (`secondApprover` must hold `policy:edit` and differ from creator) before active runs block matching tool invocations (`policy_blocked`).
5. **Audit Filtering, Formula-Safe CSV Export, Tamper Detection & Evidence Packs (`FR-GOV-17`, `FR-GOV-18`):**
   - `GET /api/v1/audit-events` filters by `action`, `actor_id`, `resource_type`, `decision`, `from_ts`, `to_ts`.
   - `GET /api/v1/audit/export?format=csv` emits RFC 4180 CSV via `formatAuditEventsCsv` with spreadsheet formula-injection neutralization and hash-chain validity status.
   - `POST /api/v1/audit/evidence-pack` bundles agent inventory, policies, tool grants, agent identities, audit samples, and `chain_verification` into a SHA-256 digested pack (`digest_sha256`).
6. **Console Governance UI (`apps/console`):**
   - Navigate to `/w/default/e/dev/governance` to export CSV, generate an Evidence Pack, author declarative policies, preview compiled Rego, simulate historical impact, promote via SoD, provision agent identities, and grant narrowed tool scopes.
