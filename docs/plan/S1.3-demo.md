## 2. Walkthrough Highlights

1. **Golden Datasets & Test Cases (`FR-EV-1`, `§7.3.9`):**
   - Create golden datasets with name, description, and tags (`POST /api/v1/eval/datasets`).
   - Add structured test cases with inputs, expected outputs, rubrics, difficulty levels (`easy`, `medium`, `hard`, `adversarial`), and weights (`POST /api/v1/eval/datasets/{id}/test-cases`).

2. **Pluggable Automated Graders (`FR-EV-2`, `Appendix N.4`):**
   - Four pluggable grading strategies:
     - `exact_match`: String & deep-object comparison with whitespace trimming and case-sensitivity options.
     - `json_schema`: Validates that actual output conforms strictly to the expected JSON schema.
     - `code_assertion`: Evaluates custom JavaScript assertion expressions in a scoped execution sandbox.
     - `llm_judge`: Evaluates multi-criteria rubrics on a `1..5` scale with mandatory rationales per item, pinned judge model, and position-bias mitigation via candidate order swapping (PRD N.4 line 2299).

3. **Experiment Runner & Regression Detection (`FR-EV-3`):**
   - Configure side-by-side or regression experiments comparing candidate agent versions against baseline versions (`POST /api/v1/eval/experiments` & `/run`).
   - Computes comprehensive aggregate metrics: `pass_rate`, `avg_score`, `min_score`, `max_score`, `total_cost_micro_usd`, `avg_duration_ms`, `regression_count`.
   - Statistical analysis: Welch's t-test p-value, statistical significance (`p < 0.05`), and small sample size warnings (`N < 5`).

4. **Configurable Release Promotion Gates (`FR-EV-4`):**
   - Enforce release gate policies (`min_pass_rate`, `min_score`, `max_cost_diff_pct`, `fail_on_critical_regression`).
   - Produces clear release verdicts: `passed`, `failed`, or `warning` with explicit lists of gate violations or satisfied criteria.

5. **Journey Test: Failed Prod Run to Passing Regression Test in < 5 Minutes (`FR-EV-8`, `§5.6 Acceptance Criteria`):**
   - Flawed production run #42 finishes with incorrect output.
   - User clicks **"Save as Test Case"** on the run trace drawer (`POST /api/v1/runs/{id}/save-test-case`), capturing inputs and establishing golden expectation.
   - User updates the system prompt to fix the flaw and publishes version v1.0.1.
   - Experiment execution evaluates all test cases against candidate v1.0.1 and baseline v1.0.0.
   - Results matrix demonstrates 100% pass rate, 0 regressions, release gate `passed`, and complete audit trail.

6. **Interactive Evaluations Console UI (`§7.3.9`, `axe-core clean`):**
   - Navigate to `/w/default/e/dev/evaluations` to explore Golden Sets, Pluggable Graders, Experiment Results Matrix, and the side-by-side Case Diff & Grader Breakdown inspector.
   - Fully accessible with zero critical axe-core violations.
