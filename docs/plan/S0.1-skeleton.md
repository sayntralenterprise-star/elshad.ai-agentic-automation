## 2. API surface for this slice (all under `/api/v1` unless noted)

| Method & path | Permission | Notes |
|---|---|---|
| `GET /health`, `GET /ready`, `GET /version` (root) | public | `/ready` checks Postgres, Redis, NATS, MinIO |
| `GET /openapi.json` (root) | public | |
| `GET /capabilities` | authenticated | edition, feature flags, enabled modules (drives UI gating) |
| `POST /auth/login`, `POST /auth/logout`, `POST /auth/refresh` | public / session | local mode only for login |
| `GET /auth/oidc/authorize`, `GET /auth/oidc/callback` | public | PKCE, state, nonce |
| `GET /me` | authenticated | principal, role bindings, workspaces |
| `GET /workspaces`, `POST /workspaces`, `GET/PATCH /workspaces/{id}` | authenticated, filtered by role bindings / `workspace:create` / `settings:edit` | creating a workspace auto-creates dev/staging/prod environments |
| `GET /workspaces/{id}/projects`, `POST /workspaces/{id}/projects` | authenticated read / `project:create` | `project:create` added per DOC-Q-025 (Org Owner, Workspace Admin) |
| `GET /workspaces/{id}/environments` | read | |
| `GET /roles`, `GET /role-bindings`, `POST /role-bindings`, `DELETE /role-bindings/{id}` | `role:assign` for writes | |
| `GET /api-keys`, `POST /api-keys`, `DELETE /api-keys/{id}` | `api_key:manage` (◐ own for Builder) | secret shown once on create |
| `GET /audit-events` | `audit:read` | basic filter + cursor pagination |

Every route declares `{ permission, scope, idempotent?, rateLimitClass }` in its contract — a test fails if any route lacks a permission declaration.

## 3. Audit chain (implement now, verify endpoint in S1.2)

Insert via a single function `appendAudit(tx, event)` that takes a per-org advisory lock, reads the last `(seq, hash)`, computes `hash = SHA256(prev_hash || canonical_json(actor, on_behalf_of, action, resource, decision, policy_ids, context_hash, ts, seq))` (PRD M.6), and inserts. Genesis `prev_hash` = 64 zeros. Canonical JSON = sorted keys, no whitespace (document it).

## 5. Exit criteria (from PRD S0.1 + E0.1 ACs)

- [ ] `docker compose up` from a clean clone brings api, engine, worker, console, Postgres, Redis, NATS, MinIO **healthy in < 3 min**; admin seeded; README quickstart verified.
- [ ] Login works (local; OIDC in integration test); org, workspace, project, environments visible in console.
- [ ] `/openapi.json` published; TS SDK builds in CI; breaking-change check active.
- [ ] RLS cross-org test and authz matrix pass; no endpoint without authorization.
- [ ] CI blocks merge on lint, type, depcruise, test, secret-scan failures; coverage reported.
- [ ] Logs are JSON with required fields; trace ids link console → API.
- [ ] Every UI page implements Loading / Empty / Error / Forbidden states; light/dark verified; keyboard nav works.
- [ ] ADR drafts exist; DoD (PRD §14) self-check written in the PR; PRD §16.2 review run and critical/high findings fixed.
- [ ] 3-minute demo script in `docs/plan/S0.1-demo.md`.

## 6. Out of scope for S0.1

Runs, agents, workflows, tools, memory, model providers, policies (beyond the `authorize` RBAC check), approvals, budgets, Helm, SAML, SCIM, MCP, real NATS event consumers (only connectivity + outbox table), audit verify endpoint, command palette actions (stub only), engine/worker business logic (processes start, report health, and exit cleanly on SIGTERM).
